# docs/

Project documentation is grouped by purpose. Start with the living development
reference in [`development/`](development/), then consult feature guidance in
[`Features/`](Features/).

| Folder | Contents |
|---|---|
| `deployment/` | Environment variable & secrets management for deployments |
| `operations/` | Runbooks for operational tasks |
| `Features/` | Current per-feature behavior and operational guidance |
| `development/` | Living project context, API reference, coding standards, and digest |
| `archive/` | Historical implementation/deployment logs for completed, one-off changes. Kept for record-keeping only — **not maintained** and not a source of truth for current behavior. |
